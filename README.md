# Raccolta esercizi linguaggio C
Questa repository è una raccolta di esercizi presi da PDF forniti dal Professore Domenico Garlisi presso Università degli studi di Palermo.
L'obiettivo è scrivere codice chiaro, leggibile e ben commentato.
Si accettano consigli e correzioni tramite pull requests e issues.


## Download:
Si può scaricare la repository nei seguenti modi:
1. Scaricare il pacchetto .zip selezionando il pulsante verde con su scritto:

> <> Code

e poi selezionare

>    Download ZIP

2.  Clonare la repository localmente (richiede Git installato sul pc)  con il comando: 
   `git clone https://github.com/Poseydone/esercizi-programmazione`
   
	 Devi copiare e incollare il comando in un terminale ed premere invio.
